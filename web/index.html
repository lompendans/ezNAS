HTTPS / TLS

Checking HTTPS configuration…

Run eznas tls generate for a self-signed certificate, or stop ezNAS and run eznas tls use /path/to/fullchain.pem /path/to/privkey.pem to use a trusted certificate. Restart ezNAS after changing certificates. Use eznas tls status to inspect certificate expiry. For automatic Let's Encrypt issuance and renewal, use an ACME client or a trusted HTTPS reverse proxy such as Caddy; direct ACME automation inside ezNAS is not implemented yet.
